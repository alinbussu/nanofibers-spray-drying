# Nanofibers, Electrospinning & Spray Drying — Pharmaceutical Research Portal

**Live Website:** https://alinbussu.github.io/nanofibers-spray-drying/

Interactive public portal and downloadable synthesis documents examining the intersection of **nanofibers / electrospinning / nanocellulose** and **spray drying / spray-freeze-drying** in pharmaceutical technology.

## What's Inside
- **Research Guide (`index.html`)**: Suitable APIs (+ 8 Candidate API Avenues), fiber-forming polymers & nanocellulose carriers, manufacturing techniques (EHD, SD, hybrid), and experimental/analytical methods.
- **Interactive Explorers**:
  - `matrix.html` — 73 Core Studies Research Matrix (22 structured engineering & analytical dimensions)
  - `core.html` — Strict Core Selection (73 studies)
  - `catalog.html` — Full Curated Pharmaceutical Catalog (620 studies)
  - `glossary.html` — Searchable Acronym Glossary (Processes, Materials, APIs, Solvents, Analytics, Data)
- **Downloadable Guides & Workbooks (`downloads/`)**:
  - `Nanofibers_Spray_Drying_Pharmaceutical_Guide.docx` (English Word guide with 300 DPI charts, 12 pt body text)
  - `Ghid_Farmaceutic_Nanofibre_Spray_Drying_RO.docx` (Romanian Word guide with 300 DPI charts, 12 pt body text)
  - `Matrice_Metode_Materiale_Nanofibre_SD.xlsx` / `.csv`
  - `Studii_Strict_Nanofibre_Spray_Drying.xlsx` / `.csv`
  - `Studii_Nanofibre_Spray_Drying.xlsx` / `.csv`
